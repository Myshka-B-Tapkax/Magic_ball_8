# 🔮 Магический шар

Магический шар, который отвечает на любой вопрос.

## 📖 Описание

Программа приветствует пользователя, спрашивает имя, а затем отвечает на любые вопросы случайными предсказаниями.

## 🚀 Как играть

1. Запустите файл `magic_ball.py`
2. Введите своё имя
3. Задайте вопрос
4. Получите ответ от магического шара
5. Если хотите ещё вопрос — напишите `да`, если нет — `нет`

## 🛠️ Что использовано

- Python 3.12
- Модуль `random`
- Функции, циклы, условия
- Валидация ввода
